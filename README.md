# Java File Handling Utility

## Internship Details
- Organization: CODTECH
- Role: Intern
- Technology: Java
- Task: File Handling Utility

## Description
This project demonstrates basic file handling operations in Java.
It includes creating a file, writing content, reading content, and modifying existing data.

## Features
- Write data to a text file
- Read data from a file
- Append new content to an existing file
- Proper exception handling

## Technologies Used
- Java
- Java I/O Package

## How to Run
1. Clone the repository
2. Compile the program:
   javac FileHandlingUtility.java
3. Run the program:
   java FileHandlingUtility

## Output
The program generates a text file named `codtech_internship.txt`
containing internship-related information.

## Conclusion
This project was developed as part of the CODTECH Internship
to demonstrate Java file handling concepts.
